### About

- Building **[Solar Iconkit](https://pub.dev/packages/solar_iconkit)** — 1,231 icons across 6 native styles for Flutter, behind a single type-safe widget
- Companion web browser at **[solar-icons-web.vercel.app](https://solar-icons-web.vercel.app)** — search, preview, and copy Flutter code
- Interested in **developer tools**, **clean typography**, and **iconography systems**
- Cambodia-based, working solo on open-source
- If any of my work saves you time, [buy me a coffee](https://ko-fi.com/sovanken) — every one counts
